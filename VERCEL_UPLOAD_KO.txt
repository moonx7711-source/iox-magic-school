이 압축파일은 마법학교 원본 화면과 기능, 이름이 새겨지는 책, 교실 접근 연출, 터치 그림판, 그린 선의 날갯짓을 함께 포함합니다.
이번 v2.0.2는 기존 v2.0.1 통합 앱에 기존 Vercel 프로젝트 연결 정보와 명시적인 정적 배포 설정을 추가한 파일 배포본입니다.

포함된 연결
마법학교 → 초대장 이름 입력 → 책에 이름이 새겨짐 → 이름 발광 + ‘터치’ 화살표 → 이름 터치 → 교실 전경 → 칠판 접근 → 칠판 아래 안내문 발광 → 자유 그림 → 안내문 또는 ‘마법 부여하기’ 터치 → 원래 선과 색을 유지하며 날갯짓/비행.

vercel.json: 정적 사이트 설정

기존 Vercel 프로젝트 업데이트 방법
1. 압축을 해제합니다. index.html과 vercel.json이 있는 폴더가 프로젝트 루트입니다.
2. 이미 연결된 GitHub 저장소를 이용한다면 이 폴더의 모든 앱 파일과 assets, classroom 폴더를 저장소 루트에 반영합니다. .vercel 폴더는 로컬 CLI 연결 정보이므로 Git에 올릴 필요가 없습니다.
3. Vercel의 기존 프로젝트에서 Framework Preset은 Other, Root Directory는 파일을 반영한 폴더로 유지합니다. 별도 설치/빌드 명령이 필요하지 않습니다. Output Directory는 . 입니다.
4. 기존 Git 연동으로 배포하거나, Vercel CLI를 설치하고 같은 팀 계정으로 로그인한 뒤 이 폴더에서 vercel --prod 를 실행합니다. .vercel/project.json이 기존 프로젝트를 지정합니다.
5. 배포 완료 후 기존 주소에서 확인합니다. 기존 로그인 보호 설정은 유지합니다.

로컬 확인
python -m http.server 8080
브라우저에서 http://localhost:8080 을 엽니다.
교실만 확인하려면 http://localhost:8080/classroom/index.html 을 엽니다.
