IOX Magic School + Living Classroom v2.0.1 (2026-10-21)

시작: index.html을 브라우저로 열거나 이 폴더를 정적 웹 서버에 올리세요.
추천 로컬 실행: python -m http.server 8080

체험 순서
1. 마법학교의 깃펜 버튼을 누르고 초대장에 이름을 입력합니다.
2. 도서관 문을 열면 마법학교 책에 이름이 새겨집니다.
3. 빛나는 이름 위 ‘터치’ 화살표를 따라 이름을 누릅니다.
4. 교실 전경에서 칠판으로 접근한 뒤 가까운 칠판으로 전환됩니다.
5. 손가락 또는 마우스로 그림을 그리고, 칠판 아래 빛나는 안내 문구 또는 ‘마법 부여하기’를 누릅니다.
6. 원래 그림의 색과 선, 지운 부분을 유지하며 날개처럼 접혔다 펴져 날아갑니다.

교실만 테스트: classroom/index.html
휴대폰: 전체 사진이 기본으로 표시됩니다. ‘크게 보기’를 누르면 칠판이 세로 화면을 채웁니다. 가로 방향도 지원합니다.
교실 위 ‘마법학교’로 돌아갈 수 있습니다. ‘교실 다시 보기’로 접근 연출을 재생합니다.
이름과 그림은 같은 브라우저의 로컬 저장소에 저장됩니다. 별도 기기 간 실시간 화면 전송 기능은 이 버전에 포함되지 않습니다.
기본 효과는 실제 그린 선의 비행입니다. 별도 실사 나비 모드와 단순 형태 검사 테스트 모드도 남겨두었습니다.
외부 라이브러리 없이 Canvas/CSS로 동작합니다. 일부 기존 화면의 웹폰트는 인터넷 연결 시 로드될 수 있습니다.

2.0.1: 안내문에 초점이 갈 때 확대 이미지의 넘침으로 장면이 스크롤되는 현상을 수정했습니다.
